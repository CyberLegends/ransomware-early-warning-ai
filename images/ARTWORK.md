# Visual assets

- `banner.png`: conceptual brand artwork generated with the built-in image-generation tool. It is not a screenshot, data diagram or claim of detection performance.
- `architecture.svg`: an exact code-authored diagram of the implemented module relationships and response boundary.
- `demo-results.png`: plotted directly from the shipped synthetic fixtures and detector output. Scores are fixture results, not real-world accuracy.

The optional `generate_visuals.py` development utility recreates the result chart with matplotlib. Matplotlib is only needed to regenerate that image; the detector, demo, reports and tests use the Python standard library. The architecture asset is editable SVG source.
