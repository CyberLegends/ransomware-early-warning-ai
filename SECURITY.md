# Security reporting

For a potential vulnerability in this project's code, contact Cyber Legends through [Cyberlegends.org](https://cyberlegends.org) to arrange a private reporting channel. Do not post credentials, operational telemetry or exploit details for a live system in public issues.

Provide the affected commit/version, a minimal synthetic reproducer, expected/observed behavior and the relevant trust boundary. Acknowledge that this release is a reference lab, with no live collection, containment or authenticated approval service. No formal response SLA or support commitment is implied.

Operational incidents should follow your organization's incident-response process rather than repository issue reporting.
